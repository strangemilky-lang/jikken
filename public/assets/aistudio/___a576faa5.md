# 「ストリップ勇者伝 - 3Dクロウラー放置RPG」引き継ぎ仕様書

## 1. コンセプト・技術構成
- **形態**：単一HTMLファイル完結（外部画像・外部ライブラリ不使用、描画は Canvas 2D レイキャスティング＋絵文字＋CSS）。
- **画面構成**：
  - 上部：`#crawler-area`（16:9固定の一人称3D迷宮レイキャスター＋右上ミニマップ＋上部HUD＋フローティングダメージ・フラッシュ枠・バナー）。
  - 下部：`#strip-shell`（高さ216pxの横長ストリップUI。左にステータス・ステージ移動・装備3枠、右に装備/宝箱/設定/ドロップログ）。
  - オーバーレイ：`#equip-drawer`（装備比較・強化ドロワー）、`#chest-modal`（宝箱ガチャモーダル）、`#milestone-modal`（100F制覇祝福）、`#offline-modal`（オフライン収益）。

## 2. 3Dダンジョンクロウラー仕様
- **迷路**：19×19の穴掘り法＋16箇所ループ破壊。階段（`🪜`）は入口 `(1,1)` からの最遠マス。
- **マッピング**：歩いたマス・隣接4マス・視線正面＆斜め前（遮蔽判定あり）のみミニマップ（`#map`）に開示。
- **速度制御と酔い対策（`crawler.speed`: ×1 / ×2 / ×4）**：
  - 戦闘・攻撃・リジェネ・遷移時間は `rawDt * crawler.speed` で完全倍速化。
  - 視覚上のカメラ移動はチラつき防止のため上限速度をキャップし、×4時は雑魚敵の配置距離を `2〜5マス先` に短縮することで実質4倍速の周回効率を維持。
  - 壁の横目地は固定4段＋距離フェード、小サイズ（640×360）時は `colStep = 1`（1px精密描画）。
- **移動モード切替（`crawler.moveStyle`）**：
  - `smooth`（デフォルト）：角の0.42マス手前から次マスへ目標を切り替える先読みコーナリング移動＋最大角速度制限によるヌルッと回転。
  - `step`：回転補間や横滑りを描画せず一定間隔でパッと進むクラシックDRPG式コマ送り。
- **100階ごとの視覚変化（`FLOOR_PALETTES`）**：
  - 1〜100F：地下迷宮（濃紺）
  - 101〜200F：黄金神殿
  - 201〜300F：紅蓮深淵
  - 301〜400F：翡翠魔窟
  - 401F〜：虚空星界（以降ループ）

## 3. ステージ・敵・迷宮イベント仕様
- **ステージ進行**：1ステージ＝Wave 1〜4（雑魚/はぐれ）＋ Wave 5（階段上のボス）。
  - 敵HP成長：`1.28^(stage - 1)`、敵ATK成長：`1.255^(stage - 1)`。
  - 敗北時は1ステージ後退してWave 1から復活（ステージ1ならその場で復帰）。
- **節目のボス**：
  - 10の倍数ステージ（100の倍数を除く）：`【守護者】` 中ボス（HP高め、封印の宝箱+2）。
  - 100の倍数ステージ：`【大魔王 / 覇王】`（HP高め、封印の宝箱+5、虹の宝箱+1）。
  - **100階初回撃破（`state.cleared100 = true`）**：称号 `👑 魔王殺し`、裏世界（101F〜）、ミシック装備、会心率100%突破（超会心・極会心）を解禁。
- **突発イベント（`crawler.events` / `isRareEscape`）**：
  - 移動ルート途中に確率で `🎁 黄金の宝箱`（レア以上確定装備＋強化石）または `🔮 謎の祭壇`（フロア終了まで 攻撃1.5x / 速度1.5x / ドロップ率2x のいずれか）を配置。
  - Wave 1〜4の12%で `👑 はぐれ黄金スライム` が出現。10秒の逃走タイマー内に撃破で強化石5倍＋レア以上確定装備＋封印の宝箱+1（逃走されてもペナルティなし）。

## 4. 装備・ステータス・計算仕様
- **装備部位（3種）**：
  - 武器（`weapon`）：メイン固定＝攻撃力
  - 防具（`armor`）：メイン固定＝最大HP
  - アクセ（`accessory`）：メイン固定＝会心ダメージ%
  - ステージごとにドロップしやすい推し部位が順繰り（`[(stage-1)%3]` が60%、他20%ずつ）。
- **レアリティ（5段階）**：
  - `0: コモン`（最大+10, サブ2）
  - `1: レア`（最大+12, サブ2〜3）
  - `2: エピック`（最大+15, サブ3〜4）
  - `3: レジェンダリー`（最大+20, サブ4）
  - `4: ミシック`（虹色・100F突破後解禁、最大+25, サブ4〜5※重複特化あり、**装備1部位につき攻撃時追撃ヒット+1（本体威力50%）**）
- **サブステ抽選プール（`SUB_POOL`）**：攻撃%、会心率%、会心ダメ%、攻撃速度%。
- **強化仕様**：
  - 強化ごとにメインステ `+12%` 複利ではなく初期値基準の線形増加 `base * (1 + level * 0.12)`。
  - `+3, +6, +9...` の3の倍数到達時、**サブステ抽選ルーレット演出**が走り、どれか1行がランダム成長（上位乱数で「大成功(神跳ね)」演出）。
- **超会心・極会心（`state.cleared100 === true` で解禁）**：
  - 会心率上限が `100%` → `300%` に解放。
  - `100%超` の確率で赤文字 `🔥超会心`（通常クリの3倍）。
  - `200%超` の確率で虹文字 `🌈極会心`（通常クリの8倍）。
  - `calcHeroStats` にも上記期待値およびミシック追撃が厳密に組み込まれており、比較画面の予想DPS増減%（緑/赤）は正確。

## 5. ガチャ的射幸心・宝箱・分解仕様
- **ドロップ時脳汁演出**：
  - レジェンダリー以上獲得時、38%で青/紫の仮表示から0.48秒後に震えて金/虹へ書き換わる**偽装昇格演出**＋画面枠フラッシュ＋Web Audioファンファーレ＋非ブロッキング上部バナー。
- **封印の宝箱ガチャ（`#chest-modal`）**：
  - 所持数：`state.chests`（通常ボスで+1等）、`state.mythicChests`（100の倍数ボスで+1）。
  - 排出基準ステージは `state.maxStage`。1個／最大10個まとめ開け／虹確定開けに対応。昇格演出＆その場装備＆自動分解連携あり。
- **分解システム**：
  - 単体分解、一括分解（コモン/レア以下/エピック以下/DPS低下のみ）、ドロップ時・宝箱開封時の自動分解設定（`-1`〜`3`）。ロック（`locked`）中と装備中は分解対象外。

## 6. セーブデータ構造（`localStorage`）
- **メインキー**：`strip_hero_idle_save_v1`
- **表示設定キー**：`strip_hero_crawl_size_v2`、`strip_hero_crawl_style_v1`
- **主な保存フィールド**：
  - `stage`, `maxStage`, `wave`, `autoProgress`, `autoSalvageRarity`
  - `stones`（強化石）, `kills`, `chests`, `mythicChests`, `cleared100`, `maxDmg`, `soundOn`
  - `equipped: { weapon, armor, accessory }`, `inventory: []`（上限80）, `logs: []`, `lastSaveTime`
- **オフライン放置収益**：10秒以上〜最大24時間（86400秒）の不在中に応じ、討伐数・強化石・装備（高レア優先）・封印の宝箱を算出してモーダル付与。
